# Diagnóstico inicial e retomada final

Atividade sem nota, respondida depois de B1: cerca de 10 minutos, até 26/09/2026, 8h, horário de Brasília. O professor lê os padrões agregados antes de B2 e os comenta na retomada, sem nomes. Não requer preparação nem informação sobre empregador.

## Familiaridade, sem juízo de valor

1. Em uma tarefa técnica, hoje uso IA: nunca / ocasionalmente / toda semana / quase todo dia.
2. O que já experimentei: conversa no navegador / assistente no editor / agente com acesso a arquivos e terminal / nenhum desses. Mais de uma resposta é possível.
3. Para verificar uma saída, hoje costumo usar: teste / leitura de código / consulta a referência / revisão por colega / ainda não tenho uma rotina. Mais de uma resposta é possível.

## Seis decisões em uma frase cada

| Objetivo | Situação e pergunta |
|---|---|
| O1 | Uma ferramenta escreveu uma função em segundos. O que ainda cabe ao engenheiro antes de entregá-la? | Revisar para ver se está correto
| O2 | Três execuções retornaram a mesma resposta. Que conclusão isso permite e qual não permite? | 
| O3 | O time quer usar IA para escrever requisitos, alterar código e publicar a mudança. O grau de autonomia deveria ser igual nessas etapas? Por quê? |
| O4 | O código e os testes propostos pelo mesmo assistente concordam entre si. O que falta verificar? |
| O5 | Um log interno contém informações que não aparecem em uma descrição abstrata do problema. Que decisão precisa ser tomada antes de enviá-lo a uma ferramenta? |
| O6 | Uma demonstração funcionou com seis exemplos fictícios. Que evidência falta antes de afirmar que a iniciativa está em uso sustentado? |

É possível escrever “ainda não sei” e apontar que informação seria necessária. Respostas curtas bastam; não se trata de acertar uma definição decorada.

## Retomada em B6

Nos 3min de retomada do fechamento, sem novo envio obrigatório, cada estudante escolhe duas respostas iniciais que mudaria e registra a razão com uma evidência produzida durante a disciplina. Esse registro integra o fechamento já previsto; não é trabalho autônomo adicional nem prova extra.

## Uso docente

O professor observa padrões agregados para dosar vocabulário e exemplos. O diagnóstico não substitui as seis evidências avaliativas, não mede produtividade e não deve ser apresentado como estudo causal de aprendizagem.
